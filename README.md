# Sales Data Analysis & Excel Dashboard

## 📊 Project Overview

This project analyzes sales data using Microsoft Excel to identify sales trends, product performance, regional performance, and key business insights.

## 🛠️ Tools & Skills

* Microsoft Excel
* Pivot Tables
* Pivot Charts
* Excel Formulas
* Data Cleaning
* Data Analysis
* Dashboard Design
* KPI Analysis

## 📈 Dashboard Features

* Total Sales KPI
* Total Quantity Sold
* Sales by Region
* Sales by Category
* Monthly Sales Trends
* Product Performance
* Interactive Pivot Tables and Charts

## 🎯 Objective

The objective of this project is to transform raw sales data into an interactive and easy-to-understand dashboard that can support business decision-making.

## 📁 Project File

The Excel workbook contains the original sales data, analysis, pivot tables, charts, and dashboard.

## 💡 Key Learning

This project demonstrates practical skills in data cleaning, Excel formulas, pivot-table analysis, data visualization, and dashboard creation.
